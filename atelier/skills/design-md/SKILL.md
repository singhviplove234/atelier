# DESIGN.md library

A bundled copy of [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, see `LICENSE`). Each file in `references/` is one brand's design system in the Google Stitch DESIGN.md format: colors, typography, layout and spacing, elevation, shapes, components, do's and don'ts, responsive behavior.

## How to use

1. **Pick the brand.** Match the user's request to a slug in the index below. If they describe a mood rather than a brand ("dark, technical, dev-tool"), shortlist 2-3 brands from the index and say which you chose and why, or ask if the choice matters to them.
2. **Read only what you need.** Read `references/<slug>.md` for the chosen brand. The files are ~30 KB each, so don't load several unless comparing.
3. **Apply it faithfully.** Use its exact tokens (hex values, font stacks, radii, spacing scale, shadows) and follow its Do's and Don'ts. Where a proprietary font is named, use the substitute the file recommends.
4. **To give the user a DESIGN.md**, copy the chosen file into their project root as `DESIGN.md` (ask before overwriting an existing one). Adapt names and colors if they want their own brand rather than a copy.

## Guardrails

- These are *inspired-by* analyses for styling reference. Don't reproduce a company's logo, trademarked name, or product copy in the user's work, and don't build pages that could pass as the real brand's site.
- Combine with other design skills (e.g. `impeccable`, `design-taste-frontend`) for layout and quality; this skill supplies the visual system.
